####################### 2.Theme (layout.tsx) #####################
####### 1.Default theme ###########
The website will take default theme of the window (for me : light)
-so no need to change the theme data

########2.Dark theme ##########

=>Option-1:No need of CSS
 <html
      lang="en"
       data-theme="dark"
      // data-theme="light"
      className={`${notoSerifBengali} h-full antialiased`} 
    >
      <body className="min-h-full flex flex-col">{children}</body>
    </html>



=>Option-2: Need CSS
//full black
 <html
      lang="en"
      className={`${geistSans.variable} h-full antialiased theme-dark`} 
    >
      <body className="min-h-full flex flex-col">{children}</body>
    </html>
 

//global.css
.theme-dark {
  background-color: #000000;
  color: white;
}
